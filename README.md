# 译页 YIYE：英文 / 日文 PDF 中文翻译网站

这是一个可运行的基础项目：网页上传 PDF，后端提取文本并调用 OpenAI API 翻译，输出中文 PDF。它尽量保留页面尺寸、图片、图形和文字块的位置，适合作为 MVP 起点。

## 先说明版面保留的边界

PDF 的“完全原版式翻译”很难自动做到 100%：中文与英文/日文长度不同；杂志可能有文字绕图、透明文字、复杂底纹、艺术字体或扫描页。当前版本会覆盖原文本区域并放入中文，尽可能保留图片与几何布局，但覆盖区域会使用白色底，可能不适合文字压在照片/纹理上的页面。扫描版 PDF 需要先接入 OCR；复杂彩页建议后续增加 OCR、背景修复、字体匹配、逐页预览和人工校对。

## 本地运行

建议 Python 3.10+。

1. 解压项目并进入目录。
2. 安装依赖：
   ```bash
   python -m venv .venv
   # Windows: .venv\Scripts\activate
   # macOS/Linux:
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. 配置环境变量：
   - `OPENAI_API_KEY`：你的 API 密钥。
   - `PDF_CJK_FONT`：支持中文的字体文件路径。Linux 常见选择为 Noto Sans CJK；Windows 可用 `C:/Windows/Fonts/msyh.ttc`；macOS 可用系统中的中文字体文件路径。
   - 可选 `OPENAI_MODEL`，默认 `gpt-4.1-mini`。
4. 启动：
   ```bash
   uvicorn app:app --host 127.0.0.1 --port 8000
   ```
5. 浏览器访问 `http://127.0.0.1:8000`。

## 部署到公网

建议部署在支持 Python 的 VPS / 云主机上，配置 HTTPS、上传大小限制、登录/限流、临时文件清理和隐私政策。不要把 API 密钥写入前端网页或提交到公开代码仓库。公开服务应补上用户认证、并发任务队列、费用控制和文件自动删除。

## 三种翻译模式

- A 原版复刻：覆盖原文字块并在原位置放入中文，尽量保留图片与版面；复杂底纹可能出现白色覆盖区域。
- B 阅读优化：采用相对更小的默认字号，优先让中文适配原文字框。
- C 双语对照：保留原始 PDF 页面，并在文件后附加按原页分组的原文/中文对照页。对照页为文字阅读布局，不是原页面上的逐字叠加。

## 当前版本限制

- 可处理包含可选中文本层的 PDF；扫描版需要 OCR。
- 复杂彩页的背景纹理、文字环绕、表格和多栏排版可能需要校对。
- 字体文件需在服务器上存在且可被进程读取。
- 翻译会产生 API 使用费用；具体费用由所选模型和输入长度决定。
- 处理受密码保护或损坏的 PDF 可能失败。


## Docker 部署（Render / 其他 Docker 云主机）

项目已包含 `Dockerfile` 和 `render.yaml`，并在 Docker 镜像中安装 Tesseract 英文、日文、简体中文 OCR 语言包及 Noto CJK 字体。

1. 将整个项目上传到你自己的 GitHub 仓库（不要提交真实 API 密钥）。
2. 在 Render 选择 New → Blueprint，连接仓库并使用 `render.yaml`。
3. 在服务的 Environment 设置 `OPENAI_API_KEY`。密钥只放在服务器环境变量中，绝不要写进 `index.html`。
4. 等待构建完成后，Render 会给出一个公网 URL。
5. 首次上线前，请先用几页、不含隐私信息的 PDF 测试输出。

注意：`render.yaml` 的 starter 计划可能产生托管费用；请在平台确认当前价格与休眠策略。生产环境还需要登录鉴权、速率限制、并发队列、文件自动清理和隐私政策。OCR 识别效果取决于扫描清晰度，复杂杂志页面仍可能需要校对。
